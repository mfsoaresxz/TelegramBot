# Bot de Validação de CPF
Este projeto é um bot para Telegram desenvolvido com o objetivo de validar números de CPF informados pelos usuários. Ele verifica se o CPF é válido de acordo com as regras oficiais de cálculo dos dígitos verificadores.

🚀 Funcionalidades
Validação de CPF: Confere se o número informado é válido.

Interação via Telegram: Usuários podem enviar CPFs diretamente no chat do bot.

Feedback imediato: Retorna se o CPF é válido ou inválido em segundos.

Tratamento de erros: Mensagens claras para entradas incorretas ou formatos inválidos.

🛠️ Linguagem utilizada
- Ocaml
